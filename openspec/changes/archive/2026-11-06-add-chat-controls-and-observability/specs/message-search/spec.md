# Spec Delta

## Purpose

提供受房间成员权限约束的聊天记录筛选和定位能力，使用户能够根据关键词、发送者和时间找到历史内容，并返回原房间上下文继续阅读。

## ADDED Requirements

### Requirement: 受权限约束的搜索
系统 SHALL 允许当前房间成员按关键词、发送者、起止时间组合查询消息，按seq有界分页，支持加载结果上下文。SQL绑定参数，关键词作为字面子串处理。

#### Scenario: 筛选与越权
- **WHEN** 成员提交筛选或非成员请求相同房间
- **THEN** 成员只得到筛选匹配的该房间消息，非成员收到room_not_found，搜索结果可跳回上下文
